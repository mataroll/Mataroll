### 💼 Highlights from Algomedia
<hr />

* **AI celebrity chatbots:** designed and built bots on the Claude API, connected them to the live chat UI, and tuned their prompts so they answer naturally and stay in character.
* **Performance:** peak CPU on Google Cloud reached 96% and threatened crashes. A Redis caching and queue layer with optimized timers brought it down to a steady 40%.
* **Revenue-critical integration:** rescued and integrated a third-party video ad platform, the site's main source of revenue, under a tight deadline.
* **CI/CD & ops:** Linux servers over SSH, Bitbucket Pipelines and GitHub Actions, separate dev environments, monitoring with Kibana.
* **Quality:** code reviews (PHP/JS) before every deploy, plus Python and Selenium automation that runs two users at once to test real-time messaging.
